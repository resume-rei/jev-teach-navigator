**この作業セッションでは、以下のWindows実機項目はすべて未確認。** 自動テストの合格、合成キーの結果、過去の練習アプリの記録でチェックを付けない。実APIはこの手順に不要。

[Windows Server 2022のCI](https://github.com/resume-rei/jev-teach-navigator/actions/runs/39168963545)ではアプリのビルドと98件の純C#自己テストが成功した。以下は利用者の対話セッションで実施する確認であり、CIの成功ではチェックを付けない。

## 準備

- [ ] 試すcommit、Windowsの版、画面倍率、モニター配置、日本語IMEを記録する。
- [ ] `./windows/build.ps1 -SelfTest`をWindowsで実行し、結果を記録する。この自己テスト自体は、物理キー・UIA実機操作・IMEの証拠にはしない。
- [ ] `./start-windows.ps1`で起動する。テストには新しく開いた架空データのウィンドウを使う。
- [ ] 操作回数を見える場所に置く。実APIキー、画像送信、マイクは使わない。

## 教示 → 保存 → 選択 → 一周

- [ ] 最初に「練習アプリを開いて案内を開始」を使い、各矢印の内容を確認して**物理Enter**で一周する。アプリ切替と対象操作が別々の承認になっている。
- [ ] 「アプリ登録・教える・保存スキル」で一般アプリの対象ウィンドウだけを登録する。アプリ名は次回も同じものを使う。
- [ ] 教示開始後に対象を右クリックする。対象が強調され、右クリック自体では実行もアプリのコンテキストメニュー表示も起きない。
- [ ] 開始画面の目印を一覧から選び、操作の意味を記す。左クリックで普段どおり操作し、操作後の結果候補を観察して、新しく現れた一意の目印を選び、1手順を追加する。
- [ ] 登録した別アプリへ移って次の手順を追加する。未登録アプリへ移った場合は教示が停止し、その間の操作を記録しない。
- [ ] 入力欄を教える場合は、実際の文章を保存する欄ではなくパラメータ名を指定する。UIAのInvoke/Valueに対応しない対象は保留になり、座標クリックや画像APIへ自動で移らない。
- [ ] 記録を停止し、下書きの全手順・入力パラメータ・最後の完了条件を確認して保存する。
- [ ] 名前・依頼例でスキルを選択する。無関係な依頼・同程度の候補は保留になる。編集内容を保存した版と、実行される版が一致する。
- [ ] 保存済みAを選んだ後に別の下書きB・取込文書・旧版を表示して開始を試す。画面と保存版の不一致を拒否し、Aや最新版を黙って実行しない。別の保存操作で最新版が変わった場合も読み直しを求める。
- [ ] 今回入力する全文を指定する。案内パネルで全文を閲覧でき、入力と送信には別々の物理Enterが必要である。
- [ ] 空欄のままでは開始できず、「空文字で欄を消去する」を明示したときだけ空文字を提案できる。空白・改行だけの指定はその文字を保持する。
- [ ] 結果を確認した後、操作を自動実行せず、次の矢印だけが出る。既に実行済みの操作を勝手に再送しない。
- [ ] 保存版を修正して新しい版を作り、旧版が残る。再起動後に同じアプリ名で現在のウィンドウを登録し、保存スキルを選び直せる。

## フォーカス・日本語IME・取消

- [ ] 一般アプリで日本語を入力・変換している間、受動的な画面再観察でナビがフォーカスを奪わない。変換確定のEnterで操作数が増えない。
- [ ] Microsoft IMEと、使用している別IMEがあればそれぞれで確認する。入力案ダイアログの改行・変換確定は案内開始にも操作承認にもならない。
- [ ] 入力案の読み取り専用欄、承認枠以外のコントロール、修飾キー付きEnterでナビが承認しない。
- [ ] 矢印表示後にEscまたは一時停止を使い、消えた提案へEnterを追加しても実行しない。再開時は現在画面から再特定する。
- [ ] 実行・結果確認の途中で停止する。すでに送ったUIA操作を取り消せるとは表示せず、結果未確認なら停止し、自動再実行しない。
- [ ] ナビにフォーカスがある状態から、承認直後・実行中にAlt+Tabで他アプリへ切り替える。結果を確認できないまま再開せず、フォーカスを自動で取り返さない。外アプリでのEsc・横スクロール・追加マウスボタンも介入として扱う。
- [ ] 練習アプリの「遷移しない」を使って結果不明にし、追加Enterでも同じ操作を再実行しない。再開・新規開始の扱いを記録する。
- [ ] 教示の右ボタンを押したまま記録停止・画面終了を行い、対応する右ボタン解放がアプリの右クリックに漏れない。
